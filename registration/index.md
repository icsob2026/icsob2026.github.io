    <h1 id="Registration" class="mb-4 text-center">Registration</h1>

    <p><b>Registration portal</b></p>
    <p>Authors of accepted papers can now register via the Chalmers registration portal: <a href="https://shop.portal.chalmers.se/shops/520" target="_blank"><strong>https://shop.portal.chalmers.se/shops/520</strong></a>.</p>

    <p><b>Author registration requirements</b></p>
    <p>Please note the following author-registration requirements:</p>
    <ul>
        <li>Each accepted paper must be covered by one author registration.</li>
        <li>One author registration covers one paper only.</li>
        <li>Authors must provide their paper ID when registering.</li>
        <li>For papers exceeding the standard page limit, the fees are:
            <ul>
                <li>One extra page: 1,250 SEK</li>
                <li>Two extra pages: 2,500 SEK</li>
            </ul>
        </li>
    </ul>
